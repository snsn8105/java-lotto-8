# java-lotto-precourse
# 로또 프로젝트

## 기능 목록

### 1. 입력 기능
-  로또 구입 금액을 입력받는다.
  - 1,000원 단위로 입력받는다.
  - 1,000원으로 나누어떨어지지 않으면 예외 처리한다.
-  당첨 번호 6개를 입력받는다.
  - 쉼표(,)로 구분하여 입력받는다.
-  보너스 번호 1개를 입력받는다.

### 2. 로또 발행 기능
-  구입 금액에 따라 로또를 발행한다.
  - 1,000원당 1장의 로또를 발행한다.
-  로또 번호를 자동으로 생성한다.
  - 1~45 범위의 중복되지 않는 숫자 6개를 생성한다.
  - `Randoms.pickUniqueNumbersInRange(1, 45, 6)` 사용
-  발행한 로또 번호를 오름차순으로 정렬하여 출력한다.

### 3. 유효성 검증 기능
-  구입 금액 검증
  - 1,000원 단위인지 확인한다.
  - 0원 이하인 경우 예외 처리한다.
-  로또 번호 검증
  - 6개의 숫자인지 확인한다.
  - 1~45 범위의 숫자인지 확인한다.
  - 중복된 숫자가 없는지 확인한다.
-  보너스 번호 검증
  - 1~45 범위의 숫자인지 확인한다.
  - 당첨 번호와 중복되지 않는지 확인한다.

### 4. 당첨 확인 기능
-  각 로또의 당첨 등수를 확인한다.
  - 일치하는 번호 개수를 계산한다.
  - 보너스 번호 일치 여부를 확인한다.
-  당첨 등수를 판정한다.
  - 1등: 6개 일치
  - 2등: 5개 일치 + 보너스 번호 일치
  - 3등: 5개 일치
  - 4등: 4개 일치
  - 5등: 3개 일치

### 5. 당첨 통계 기능
-  각 등수별 당첨 개수를 집계한다.
-  총 당첨 금액을 계산한다.
-  수익률을 계산한다.
  - (총 당첨 금액 / 구입 금액) × 100
  - 소수점 둘째 자리에서 반올림한다.

### 6. 출력 기능
-  구매한 로또 개수를 출력한다.
-  발행된 로또 번호 목록을 출력한다.
-  당첨 통계를 출력한다.
  - 각 등수별 당첨 개수
  - 총 수익률
-  에러 메시지를 출력한다.
  - "[ERROR]"로 시작하는 메시지

### 7. 예외 처리 기능
-  잘못된 입력에 대해 `IllegalArgumentException` 발생
-  에러 발생 시 해당 부분부터 재입력 받기

## 프로그래밍 요구사항 체크리스트

### 코드 스타일
- indent depth 2 이하 유지
-  3항 연산자 사용하지 않기
-  메서드 길이 15라인 이하
-  else, switch/case 사용하지 않기
-  Java Enum 적용
-  Java 코드 컨벤션 준수

### 테스트
-  JUnit 5와 AssertJ로 단위 테스트 작성
-  UI 로직 제외하고 모든 기능 테스트
-  기능 목록 단위로 테스트 작성

### 클래스 설계
-  Lotto 클래스: numbers 필드만 사용, private 유지
-  각 기능별로 적절한 클래스 분리
-  메서드는 한 가지 일만 수행
